# Security policy

`pi-sap-aicore` runs inside Pi sessions with access to SAP AI Core credentials. Please
report anything that could expose those credentials, run unintended code, or tamper
with the published package.

## Reporting a vulnerability

Report it privately through this repository's
[Security tab](https://github.com/ttiimmaahh/pi-sap-aicore/security/advisories/new),
and keep the details out of public issues and PRs until a fix is released.

Include the affected version, steps to reproduce, and the impact you expect. Leave out
real service keys, tokens, and tenant details.

## Supported versions

Security fixes go into the latest release on npm.
